# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful and constructive, and no harassment of any kind, in issues, pull requests
and anywhere else you take part on the project's behalf.

To report unacceptable behaviour, contact the maintainers privately through GitHub (the
**Security** tab's **Report a vulnerability** form reaches them privately). Reports are
handled in confidence, and the maintainers may remove, edit or reject contributions, or
block anyone, as the Covenant describes.
